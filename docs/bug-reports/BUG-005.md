# BUG-005 — Sistema permite múltiplos check-ins no mesmo dia

**Caso de Teste:** CT-014
**Severidade:** Alta

## Localização do Erro
Backend — checkin.controller.js (função create)

## Passos para Reproduzir
1. POST /api/checkins com foto válida como MEMBER
2. POST /api/checkins novamente com outra foto no mesmo dia

## Resultado Esperado
Segundo check-in bloqueado com mensagem de limite diário.

## Resultado Atual
Segundo check-in aceito com status 201. Usuário acumula
10 pontos a cada envio sem nenhum limite diário.

## Análise de Causa Raiz
O controller de check-in não verifica se o usuário já
realizou um check-in na data atual antes de criar um novo.
Falta uma validação que consulte check-ins do usuário
no dia corrente antes de permitir a criação.
