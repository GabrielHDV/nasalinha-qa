# BUG-001 — Reset de senha não funciona

**Caso de Teste:** CT-008
**Severidade:** Crítico

## Localização do Erro
Backend — auth.controller.js (função resetPassword)

## Passos para Reproduzir
1. Ir em "Esqueci minha senha" na tela de login
2. Informar pedro@example.com
3. Clicar no link que chega no Mailtrap
4. Digitar nova senha e confirmar
5. Tentar logar com a nova senha
6. Tentar logar com senha123 (antiga)

## Resultado Esperado
A nova senha funcionar e a antiga ser bloqueada após o reset.

## Resultado Atual
Login com a nova senha retorna "Credenciais inválidas".
A senha antiga continua funcionando normalmente.
O sistema exibiu mensagem de sucesso mesmo sem salvar a nova senha.

## Análise de Causa Raiz
Em auth.controller.js, a função resetPassword() gera o hash
da nova senha mas não inclui o campo password na query de
atualização do banco:

UPDATE "users" SET "updatedAt" = $1

Faltou incluir: password = hashedPassword
