# BUG-002 — Admin aparece no ranking geral

**Caso de Teste:** CT-020
**Severidade:** Alta

## Localização do Erro
Frontend — página de Ranking / Backend — endpoint GET /api/rankings

## Passos para Reproduzir
1. Logar como admin@nasalinha.com
2. Fazer um Novo Check-in com qualquer foto
3. Acessar o Ranking Geral

## Resultado Esperado
O Admin não deveria aparecer no ranking pois não compete
com os membros da equipe.

## Resultado Atual
Admin Sistema aparece na lista de classificação junto com
os membros, com 10 pontos e badge "Você".

## Análise de Causa Raiz
O endpoint /api/rankings não filtra usuários pelo campo role
antes de montar a lista. Usuários com role ADMIN deveriam
ser excluídos da consulta de ranking.
