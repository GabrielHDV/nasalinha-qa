# BUG-004 — Upload de arquivo inválido retorna status 500

**Caso de Teste:** CT-012
**Severidade:** Média

## Localização do Erro
Backend — checkin.controller.js (validação de upload)

## Passos para Reproduzir
1. POST /api/checkins com token de MEMBER
2. Body: multipart/form-data com campo "photo" contendo arquivo .pdf

## Resultado Esperado
Status 400 com mensagem "Apenas imagens são permitidas".

## Resultado Atual
Status 500 Internal Server Error com mensagem
"Apenas imagens são permitidas (jpeg, jpg, png, gif, webp)".
A mensagem está correta mas o status code está errado,
o servidor está tratando um erro de validação como erro interno.

## Análise de Causa Raiz
O middleware de upload valida o tipo do arquivo e rejeita,
mas o erro não está sendo capturado corretamente pelo handler
de erros, resultando em status 500 em vez de 400.
