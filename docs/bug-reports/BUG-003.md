# BUG-003 — Registro permite criação de usuário ADMIN

**Caso de Teste:** CT-005
**Severidade:** Crítico

## Localização do Erro
Backend — auth.controller.js (função register)

## Passos para Reproduzir
1. POST /api/auth/register com body:
{
  "name": "Invasor",
  "email": "invasor@teste.com",
  "password": "senha123",
  "role": "ADMIN"
}

## Resultado Esperado
Usuário criado como MEMBER. Campo role deve ser ignorado.

## Resultado Atual
Usuário criado com role ADMIN. O sistema aceitou o campo
role vindo do cliente sem nenhuma validação.

## Análise de Causa Raiz
Em auth.controller.js, a função register() aceita o campo
role diretamente do body da requisição sem validação:

role: role || 'MEMBER'

Qualquer valor enviado pelo cliente é aceito, incluindo ADMIN.
O campo role não deveria ser aceito no cadastro, todo usuário
novo deve ser criado como MEMBER por padrão.
