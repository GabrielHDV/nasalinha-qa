# BUG-006 — Deletar check-in não subtrai pontos do usuário

**Caso de Teste:** CT-019
**Severidade:** Alta

## Localização do Erro
Backend — checkin.controller.js (função delete)

## Passos para Reproduzir
1. GET /api/rankings — anotar pontos do Lucas (110pts)
2. DELETE /api/checkins/{id} como ADMIN
3. GET /api/rankings novamente

## Resultado Esperado
Pontos do Lucas reduziram em 10 (de 110 para 100).

## Resultado Atual
Pontos do Lucas continuam 110 após o check-in ser deletado.
O ranking fica incorreto pois contabiliza pontos de
check-ins que não existem mais.

## Análise de Causa Raiz
A função de delete no checkin.controller.js remove o registro
do check-in mas não atualiza a tabela de pontos do usuário.
Falta uma query que subtraia os pontos ao deletar.
