# 📸 Evidências de Teste

Esta pasta contém as evidências coletadas durante a execução dos testes de QA realizados no sistema **NaSalinha**.

As evidências foram organizadas por bug report para facilitar a rastreabilidade, reprodução e análise dos problemas encontrados.

---

# 📂 Estrutura

```bash
evidencias/
├── BUG-001/
├── BUG-002/
├── BUG-003/
├── BUG-004/
├── BUG-005/
├── BUG-006/
```

Cada pasta contém materiais relacionados ao bug correspondente, como:

- Prints de tela
- Capturas do Insomnia
- Logs da aplicação
- Evidências de comportamento incorreto
- Mensagens de erro
- Resultados inesperados

---

# 🔍 Objetivo das Evidências

As evidências auxiliam na:

- Reprodução dos bugs
- Validação dos testes executados
- Análise técnica das falhas
- Comunicação com desenvolvimento
- Comprovação dos resultados documentados

---

# 🧪 Ferramentas Utilizadas

As evidências foram coletadas utilizando:

- Insomnia
- Navegador Web
- Logs do terminal Docker
- Console do navegador (F12)

---

# 📌 Observação

Cada pasta está diretamente relacionada ao seu respectivo Bug Report documentado em:

```bash
/docs/bug-reports
```

Exemplo:

```bash
BUG-001 → evidencias/BUG-001
BUG-002 → evidencias/BUG-002
```
